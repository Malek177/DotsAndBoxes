## Why the early commits come from one account

We worked on this project together on one laptop, so the early commits were all
pushed from one GitHub account (Malek177). To credit both of us, we set the Git
author name on that laptop to "Malek & Jasson", so every commit made before
November 18, 2026 shows that author. You can check this with `git log`. GitHub
shows those commits under Malek177 because they use that account's email
address.

Our professor advised us that it is better to add the teammate to the
repository as a contributor. On November 18, 2026 we added Jasson (jasonlmatta)
as a collaborator. From now on, each of us commits under our own name and
GitHub account.
